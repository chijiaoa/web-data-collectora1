# web-data-collector

> A skill for collecting and organizing data from public websites.

Automatically scrape, clean, and export data from any public webpage — to CSV, JSON, Notion, or Google Sheets.

## Features

- Scrape structured data from public web pages
- Clean and deduplicate results automatically
- Export to CSV, JSON, Notion database, or Google Sheets
- Support scheduled runs (hourly / daily / weekly)
- Handle pagination and infinite scroll

## Quick Start

Install via Claude Code:

```bash
npx skills add chijiao/web-data-collector
```

Or with bunx / pnpm:

```bash
bunx skills add chijiao/web-data-collector
pnpm dlx skills add chijiao/web-data-collector
```

## Example Usage

```
"Scrape all job listings from this URL and save to CSV"
"Monitor this product page and alert me when the price drops"
"Collect all articles from this blog and export to Notion"
```
